사이트 열기

압축을 완전히 해제한 뒤 index.html 파일을 더블클릭하세요. Chrome·Edge·Safari 등 일반 브라우저에서 바로 열립니다. 별도의 웹서버나 회원가입 없이 1~28편을 모두 읽을 수 있습니다. 홈 화면의 왕궁 사진과 외부 자료 링크는 인터넷 연결이 필요합니다.

집필 현황과 원고의 성격

1~28편 전체 본문이 작성되어 있습니다. 1~16편은 이전 대화의 핵심 사건과 흐름을 토대로 재구성한 학습 원고이며, 이전 답변의 문장·표·인용을 빠짐없이 복제한 원문은 아닙니다. 17~28편은 이후에 상세 집필한 시대별 원고를 반영했습니다. 모든 편은 역사 학습 자료로서 사료·학술적 논의와 비교하며 읽으시기를 권장합니다.

HTML과 Markdown의 관계

era-01.html부터 era-28.html까지가 바로 열어볼 수 있는 학습 페이지입니다. chapters/01.md부터 chapters/28.md까지는 각 페이지의 편집용 원고입니다. metadata.json에는 제목·연대·검색어·집필 상태가 기록되어 있습니다. build_site.py를 실행하면 원고와 메타데이터를 기준으로 28개 본문, 홈페이지, 안내·출처 페이지가 다시 만들어집니다.

내용 수정 방법

  1. 수정할 편의 원고(예: chapters/17.md)를 메모장이나 Markdown 편집기로 엽니다.
  2. 본문을 고치고 UTF-8로 저장합니다. 제목·연대나 검색어를 바꾸려면 metadata.json도 함께 수정합니다.
  3. Python 3가 설치되어 있다면 최초 한 번 python -m pip install mistune를 실행합니다.
  4. 사이트 최상위 폴더에서 python build_site.py를 실행하고 index.html을 새로고침합니다.

주의: HTML을 직접 수정하는 것도 가능하지만 빌드 스크립트를 실행하면 HTML은 Markdown 내용으로 다시 생성됩니다. 수정 사항을 오래 유지하려면 chapters/*.md 파일을 편집하세요.

찾기와 이동

홈페이지에서 시대명·연도·인물을 검색하거나 선사·고대 / 중세 / 근세 / 근현대 중 하나로 걸러볼 수 있습니다. 왼쪽 시대 목록과 각 편 하단의 이전·다음 이동 링크를 이용해 순서대로 학습할 수도 있습니다. 모바일에서는 시대 목록이 상단의 가로 스크롤로 표시됩니다. 표는 화면이 좁을 때 표 내부만 가로로 스크롤됩니다.
