# 스페인 역사 공부 — 전체 28편 통합판

이베리아반도의 선사시대부터 2026년까지의 역사를 다루는 한국어 정적 HTML 학습 사이트입니다.
**28개 시대의 상세 본문이 모두 작성되어 있습니다.** 최종 통합: 2026-10-20.

## 사이트 실행

1. ZIP의 **전체 파일과 폴더를 함께** 압축 해제합니다.
2. 최상위의 `index.html`을 더블클릭합니다.
3. 전체 목차에서 시대별 카드를 선택하거나 제목·인물·연도를 검색합니다. 시대별 필터도 사용할 수 있습니다.
4. 페이지 상단/측면 시대 목록, 하단 이전·다음 시대 링크를 통해 연속 학습할 수 있습니다.

회원가입, 별도 웹서버, 외부 JS/CSS 라이브러리는 필요하지 않습니다.
본문·스타일·검색 기능·간략한 국기 그림은 오프라인에서 작동합니다. **홈페이지 왕궁 사진과 외부 참고 링크는 인터넷 연결이 필요합니다.**

## 집필 및 자료 상태

- **1~16편:** 앞선 대화의 주요 내용을 토대로 재구성한 학습 원고입니다. 원래 답변 모든 문장과 그림을 그대로 복제한 것은 아닙니다.
- **17~28편:** 이후에 작성한 상세 HTML 원고를 반영했습니다. `chapters/17.md`~`28.md`와 HTML을 동기화했습니다.
- **28편 현대사:** 정치·사회 현황의 기준 날짜는 2026년 10월 20일입니다. 선거 결과나 새로운 정책이 발표되어도 사이트가 자동으로 업데이트되지는 않습니다.

## 파일 구성

```text
spain-history-site/
├── index.html                 전체 시대 목차, 검색, 시대별 필터
├── era-01.html ~ era-28.html  시대별 HTML 페이지 28개
├── guide.html                 이용 및 원고 관리 안내
├── credits.html               이미지·자료 출처
├── metadata.json              제목, 기간, 집필 상태, 검색 키워드
├── chapters/
│   └── 01.md ~ 28.md          HTML을 다시 만들기 위한 편집용 원고
├── assets/
│   ├── style.css              PC·모바일 반응형 스타일
│   ├── site.js                목차 검색·필터·이미지 오류 처리
│   └── flag-civil.svg         오프라인용 민간기 도안
└── build_site.py              전체 사이트 재생성 스크립트
```

## 원고 수정과 재생성

1. `chapters/17.md`와 같이 수정할 번호의 Markdown 파일을 텍스트 편집기로 엽니다.
2. 사건·연표·문장을 수정하고 **UTF-8**로 저장합니다. 제목·시대 구분·연대·검색 키워드는 `metadata.json`에서 변경할 수 있습니다.
3. PC에 Python 3가 설치되어 있으면 처음 한 번만 아래 명령어를 실행합니다.

   ```bash
   python -m pip install mistune
   ```

4. 사이트 최상위 폴더에서 실행합니다.

   ```bash
   python build_site.py
   ```

5. `index.html`을 새로고침합니다. 28개 시대 페이지·홈페이지·가이드·출처 페이지가 **현재 원고와 메타데이터 기준으로 일괄 재생성**됩니다.

**중요:** `era-17.html`을 직접 수정하여 덮어써도 브라우저에서 확인할 수 있습니다. 다만 이후 `build_site.py`를 실행하면 해당 HTML이 `chapters/17.md` 내용으로 교체되므로, **지속적으로 보관할 수정은 Markdown에 반영**해야 합니다.

## 학습과 화면 배치

- 홈에서 시대별 필터: 전체 / 선사·고대 / 중세 / 근세 / 근현대.
- 검색: 제목, 간략 제목, 시대·연도, 관련 키워드.
- 본문: 목차 접기·펴기, 이전·다음 편 링크, 모바일 가로 스크롤 표.
- 별도 서버 없이 페이지를 파일로 열 수 있습니다.
